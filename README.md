# mbl-fog-dew-thermodynamics

Este repositorio contiene el código de análisis, las figuras generadas y los borradores del del escrito borrador de tesis final.ß

## 📁 Estructura del Repositorio

*   **`borrador_escrito.qmd`**: Archivo fuente en Quarto con la estructura, metodología, resultados y discusión del manuscrito.
*   **`borrador_escrito.pdf`**: Versión compilada y renderizada del manuscrito lista para revisión.
*   **`figuras_finales_paper.R`**: Script principal en R que procesa las matrices de datos y genera los gráficos multipanel con `ggplot2` y `patchwork`.
*   **`references.bib`**: Archivo de soporte bibliográfico con las citas del paper en formato BibTeX.
*   **Recursos Visuales (`.png`)**:
    *   `resultados_figura01.png`: Análisis global de eventos anuales y comparación metodológica.
    *   `resultados_figura02.png`: Distribución y respuesta de eventos a lo largo del gradiente altitudinal.
    *   `resultados_figura03.png`: Dinámica temporal de recolección (frecuencias relativas mensuales/horarias).
